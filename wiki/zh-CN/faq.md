# 常见问题

这页整理当前版本里最常见的行为说明。后台任务频率以你自己的 `config.toml` 为准。

## 元数据插件网络与代理

内置元数据插件会访问以下域名：

```text
adult.contents.fc2.com
storage*.contents.fc2.com
contents-thumbnail*.fc2.com
fc2cmadb.com
api.video.dmm.co.jp
video.dmm.co.jp
awsimgsrc.dmm.co.jp
pics.dmm.co.jp
www.javbus.com
```

宿主机能访问不代表容器能访问。外部站点请求使用 `sakuramedia` 容器的环境变量 `HTTP_PROXY`、`HTTPS_PROXY` 和 `NO_PROXY`；只配置 Docker daemon 或宿主机代理不会自动传给容器。

排查顺序：

1. 在「概览 → 组件诊断」运行检测。它会在容器内用测试番号实际请求每个已启用的元数据源：「无数据」表示网络可达但没有命中测试番号，「失败」再继续检查网络或插件配置。
2. 在部署机器上检查固定域名的 DNS 和连通性。如果部署机器有 `curl`，可以执行：

   ```bash
   for host in adult.contents.fc2.com fc2cmadb.com api.video.dmm.co.jp video.dmm.co.jp awsimgsrc.dmm.co.jp pics.dmm.co.jp www.javbus.com; do
     curl -sS -o /dev/null -w "$host %{http_code}\n" --max-time 10 "https://$host"
   done
   ```

   `storage*` 和 `contents-thumbnail*` 是通配子域名，由组件诊断的实际请求验证。
3. 检查软路由或透明代理是否把这些域名分流到了不可用的出口。
4. 需要代理时，在 compose 的 `sakuramedia.environment` 中配置：

   ```yaml
   HTTP_PROXY: "http://192.168.1.1:7890"
   HTTPS_PROXY: "http://192.168.1.1:7890"
   NO_PROXY: "localhost,127.0.0.1,postgres,qbittorrent"
   ```

   代理地址必须是容器能访问的地址；容器内的 `127.0.0.1` 通常指向容器自身，而不是宿主机。`NO_PROXY` 中要保留内网索引器、qBittorrent、PostgreSQL 等地址，避免内网请求被送进代理。修改后重启 `sakuramedia` 容器。

索引器、下载 provider 和媒体 provider 的连接参数仍在各自配置中填写。

## 账号与登录

### 忘记用户名或密码了怎么办？

在后端容器运行 `reset-account`，用新的用户名和密码重建账号：

```bash
docker exec -it --user app -w /app sakuramedia python -m src.start.commands reset-account
```

也可以使用 `--username` 和 `--password` 直接传参。命令会清空 refresh token，已登录客户端需要重新登录。详见[常用命令](/zh-CN/guide/commands#重置账号)。

## 搜索与数据

### 按番号搜索或导入影片失败怎么办？

当前版本只使用已启用的元数据插件，并按「设置 → 元数据源」中的顺序调用。官方镜像已内置 DMM / FANZA、FC2、FC2CMADB 和 JavBus 四个元数据源。先在插件页对相关插件运行「能力测试」，再到「概览 → 组件诊断」查看每个来源的结果：「无数据」表示插件可达但测试番号没有命中，「失败」时继续检查插件配置和网络。当前版本要求所有插件声明 Host API 18；未按 18 重新发版的旧插件无法加载。

### 在线搜索入库影片或女优失败

先在「概览」页运行「组件诊断」，确认媒体库、元数据源和索引器连通；元数据源会逐个显示测试结果，再检查容器网络、代理规则和 DNS。元数据插件自身的错误可在手动匹配的来源错误提示或后端日志中查看。

封面和剧照由元数据插件交付给宿主；头像由后端从 GFriends 下载。如果软路由开启了透明代理，检查相关域名是否被分流到不可用的出口；访问失败时图片会缺失。元数据插件的域名和容器代理配置见[元数据插件网络与代理](#元数据插件网络与代理)。

### 为什么刚启动后看不到影片或女优？

本地搜索只查询已入库数据。首次部署后，打开搜索页的「联网」开关执行一次在线搜索，成功结果会写入本地库。

### 为什么“女优上新”是空的？

该页面展示本地影片中关联到已订阅女优的近期作品。系统会通过声明演员作品列表能力的元数据插件同步作品资料；当前内置的 JavBus 支持这项能力。后台任务名为「订阅演员影片同步」，默认每天 02:00 执行，首次抓取会全量扫描，之后按增量检查。

依次确认：已经订阅女优、同步任务运行成功、元数据插件可以联网。刚订阅尚未同步或近期没有新作时也可能为空。女优订阅不会主动订阅她的影片，看到想看的作品后仍需要单独订阅影片。任务说明见[后台任务](/zh-CN/guide/tasks#订阅演员影片同步)。

### 为什么看不到互动数、热度或评论？

影片互动数、热度和评论都由插件提供。官方镜像没有内置这类插件；未安装或未在「设置 → 元数据源」绑定互动数/评论来源时，前端会隐藏相关区域。安装兼容插件后，再分别选择来源。

### 以图搜图需要什么条件？

图库来自可播放媒体生成的缩略图，特征提取由 SigLIP2 嵌入服务完成，向量存放在 Qdrant。三者都准备好后，后台任务会逐步生成和索引图片。

如果结果为空，先在「概览」页检查嵌入服务，再在任务中心运行「媒体缩略图生成」「以图搜图缩略图向量索引」和「以图搜图剧情图向量索引」。

## 媒体库与导入

### 导入普通视频时如何选择来源？

进入「管理 → 资源导入」，切换到「视频」，新建导入并选择目标媒体库，再使用来源浏览器选择文件或目录。导入前确认是否保留源文件。

普通视频可以归入视频合集；导入任务完成后，在合集页调整成员顺序即可。详情见[普通视频与视频合集](/zh-CN/guide/videos)。

### 导入时提示“文件太小”怎么办？

影片导入会使用 `[media].allowed_min_video_file_size` 过滤过小的视频，默认值为 256 MB。需要导入更小的视频时，在系统设置或 `config.toml` 中调低该值。

### 为什么影片已经订阅了，但没有自动下载？

自动下载需要同时满足：影片还没有可播放媒体、索引器能返回候选、索引器已绑定下载器，且下载器 provider 配置可用。可以先运行组件诊断，再在任务中心手动触发「已订阅缺失影片自动下载」。

### 自动下载如何选择候选？

候选必须有可用来源、体积在 `1 GiB` 到 `40 GiB` 之间且做种数大于 `0`。系统按体积从大到小排序，并使用索引器名称和标题稳定排序；提交时使用该索引器绑定顺序中的第一个下载器。

### 下载完成后如何进入媒体库？

下载 provider 返回 `completed` 和 `completed_source_ref` 后，后台任务会将该来源交给目标媒体库 provider 导入。检查时依次确认：下载器状态已同步、任务含完成来源引用、媒体库 provider 配置可用，以及「已完成下载自动导入」任务没有失败。

### 原地导入后媒体失效

原地导入的媒体直接引用源文件。源文件被移动、重命名或内容变化后，媒体会失效；删除 SakuraMedia 中的媒体记录不会删除源文件。需要固定文件位置，或改用「保留源文件」导入。

## 播放与解码

### 播放地址从哪里来？

后端为每个媒体生成带签名的 `play_url`，客户端使用该地址播放。签名地址有有效期，客户端会在需要时重新获取。

### 播放时是否需要服务端转码？

播放解码由客户端完成。播放器能否硬件解码取决于当前设备、系统和媒体编码；服务端负责提供媒体和签名播放地址。

### 播放卡顿时先检查什么？

先确认媒体库 provider 连通、`play_url` 能在客户端打开，再检查客户端设备的解码能力和网络带宽。可以在「概览」页运行组件诊断。

## 任务中心

### 通知中心和任务中心分别看什么？

通知中心展示提醒；任务中心展示后台作业的状态、进度、结果和错误信息。下载同步、自动导入、缩略图、图片索引、插件任务等都在任务中心查看。

### 下载任务可以删除吗？

可以。在下载任务列表删除时选择是否让 provider 同步删除远端任务及文件。删除只移除选中的任务记录，不会删除已经导入媒体库的影片。

## 切片与视频合集

### 删除媒体后，时刻还在吗？

当前版本会随媒体删除关联时刻及其合集成员关系。时刻不支持脱离媒体后自动接回。已生成的独立切片会保留，清理前请先验证切片可播放。详见[媒体库管理](/zh-CN/manual/media-management)。

### 切片存在哪里？

切片是独立的 mp4 文件，存放在 `[media].media_clip_root_path`（默认 `/data/media-clips`）。该目录需要持久化，删除来源影片不会删除切片文件。

### 为什么切片过长或生成失败？

单个切片时长受 `media_clip_max_duration_seconds` 限制，ffmpeg 执行时间受 `media_clip_ffmpeg_timeout_seconds` 限制。调整方式见[配置说明](/zh-CN/guide/config#media)。

### 视频合集可以连续播放吗？

可以。合集保存视频成员及顺序，播放时客户端按顺序播放；同一个视频可以加入多个合集。
