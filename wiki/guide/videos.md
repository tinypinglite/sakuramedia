# 普通视频与视频合集

普通视频用于管理没有 JavDB 元数据的内容，例如个人收藏、录制或剪辑的视频。它与影片目录共用播放、缩略图和播放进度能力，使用视频合集来组织内容。

## 导入普通视频

1. 进入「管理 → 媒体导入」，选择「普通视频」。
2. 选择目标媒体库。
3. 在来源浏览器中选择 provider 提供的文件或目录。
4. 选择视频合集（也可以在这里新建），然后提交导入。

来源由媒体库 provider 提供。界面保存的是 provider 能理解的 `source_ref`，不要求填写宿主机路径或下载器路径；同一个导入流程可以使用不同 provider 的存储实现。

导入是后台任务。任务中心会显示扫描、导入和失败统计；完成后，视频会进入媒体库并出现在对应合集里。视频标题默认取 provider 返回的名称，合集成员可以调整顺序。

## 管理视频合集

- 一个视频可以加入多个合集。
- 合集只保存成员关系和顺序，不复制视频文件。
- 删除合集不会删除视频；删除视频时会同步移除它在合集中的成员关系。
- 播放合集时，客户端按成员顺序播放每个视频。

普通视频不依赖番号元数据，搜索、订阅和影片元数据编辑仍属于影片目录的功能。
