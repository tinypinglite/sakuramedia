# Start watching

Once the movie details show available media, you can play. If there is only a cover and a description, [download](./first-movie) or [import a file](./import) first.

[Want the full flow? Play the 45-second demo →](/#demo)

## Choose a media version

Go to the movie details, find the media list, and pick the media to play based on file name, size, media library and other information. Different versions of the same movie may have different quality, intro or cut, and the saved playback position belongs to a specific media item.

When a viewing progress exists, entering playback normally starts from the beginning and shows a resume prompt once the player is ready. Choose "Continue playing" to jump to the previous position; when you enter from a thumbnail or a moment, the position you picked is used instead.

## Use thumbnails to find what you want to see

Both the desktop and mobile players have a thumbnail panel beside them (expanded by default; the switch in its top-right corner collapses or reopens it):

1. Browse the frames and look for scenes you are interested in.
2. Click a thumbnail to jump to that position and play.
3. Switch the thumbnails to follow playback, or scroll through them yourself.

Thumbnails are generated by a background task and are not necessarily ready at the moment the import finishes. When the panel has no images, check the "Media thumbnail generation" run in the task center; having media does not mean all thumbnails exist.

## Subtitles and playback controls

Use the player control bar for play, pause, volume, fullscreen and playback speed. The subtitle button selects from currently available subtitles; when there are none, fetch or import subtitles first — the button does not conjure them up.

Subtitle fetching depends on existing subtitle data, enabled plugins and available resources. See [Recommended plugins](/guide/plugins) for installing plugins.

Mobile playback controls differ from the desktop ones; the thumbnail panel switch is in the player's top-right corner and can be collapsed or expanded at any time. System settings and bulk management steps follow the desktop tutorials.

Mobile playback opens in landscape with the system bars hidden. Drag up or down on the left half of the screen to change the app's brightness, or on the right half to change media volume. Leaving playback restores the app brightness, while media volume keeps the system setting. The player page is already full-screen, so the mobile control bar has no separate fullscreen button.

## When playback is not smooth

| Symptom | Check first |
| --- | --- |
| No media to choose | Whether the download finished and the import succeeded |
| Media exists but will not open | Whether the media library and the actual file are reachable; reopen the media and try again |
| Plays but stutters | The network between client and storage, and the device's decoding capability for that codec |
| No thumbnails | Whether thumbnail generation has finished |
| No subtitles to choose | Whether subtitles for this movie exist |

Decoding happens in the client, so network, device and video codec all affect the experience. See [Playback and decoding FAQ](/faq#playback-and-decoding) for details.
